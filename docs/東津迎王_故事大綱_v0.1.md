## 0. 取材重點（真實祭典，已查證）

- 迎王是三年一科的祭典，迎接「代天巡狩」的五位千歲爺巡狩地方，**驅除瘟疫與孤魂野鬼**。
- 地方大廟（東隆宮，主祀溫府千歲）在祭典期間改稱「代天府」，作為千歲爺的行館；溫王爺是祭典的領導者，遶境前導、過火開路。
- 程序：七角頭抽籤分職務 → 造王船 → 請王（海邊請水）→ 過火 → 遶境祈福 → 遷船遶境（王船上岸「陸上行舟」）→ 宴王 → **送王（燒王船）**。
- 王船的作用是送走千歲爺，**同時把鎮上的邪煞、疫鬼一併帶走**。送王時王船推到沙灘，四周堆滿金紙、米包與替身，道長開出通往外海的水路，再點火。

## 4. 本章專屬：判決「上王船」

- 夜審多一個判決：**上王船**——不審了，讓牠跟著王船出海。
- 任何鬼都可以上王船（不用查明），**不加戾氣**；但牠的冤情沒解，信徒錄記「隨船走了」（不算圓滿也不算遺憾）。
- 上王船的鬼越多，王船越重：**最後一戰王船走得越慢**（要守更久）。
- 用意：給玩家一個「不斬、也不必全部查清楚」的出口，但有代價。

## 6. 案子（四個鬼）

### 案一：抓著斷舵的老船長「海伯」（主線，接最後一戰；相當於第一章的阿福）
- **白天**：港口最邊邊的繫船柱旁，一個老人雙手抓著一截斷掉的舵，望著海。
- **真相**：三年前那場颱風，是他堅持出海，船沉了，船員都沒回來（蔡嫂的丈夫是其中一個）。他自己被沖上岸，隔年病死。他說「海是吃人的」，其實是不敢面對自己。
- **證據**：蔡嫂的話（「那天船長說最後一網」）、斷舵上刻的船名、港務的舊報紙、黃總理說的颱風那年。
- **判決**：收編→最後一戰他能喊船員的名字（說動黑潮）；超渡→技能；上王船→跟船走。

### 案二：宿舍外的外籍船員「阿迪」
- **白天**：船員宿舍外，一個年輕人坐在冰櫃上，手裡捏著一封沒寄出的信。
- **真相**：他在海上出事，船東沒有通報，他家鄉的家人到現在還在等他寄錢回家。他不是作祟，只是一直把宿舍的燈弄閃，想讓人注意到那封信。
- **證據**：阿娟的話、宿舍的值班紀錄、信封上的地址。
- **判決**：查明＋阿娟傳話→信寄出去（超渡）；這一件**斬了算斬錯**。
- 語氣：寫他的思念與等待，不寫事故細節，不指涉真實國籍以外的刻板印象。

### 案三：偷米包的孤魂「米婆」（溫暖、罪很小）
- **白天**：王船廠堆米包的地方，一個瘦小的老婦人每晚偷一包米。
- **真相**：她生前是港口煮飯給船員吃的，死後沒人祭祀。她偷米不是自己吃，是放在港口給「沒回來的那些人」。
- **證據**：洪師傅（米包每晚少一包）、港口繫船柱下的一碗生米、黃總理（以前港口有個煮飯的阿婆）。
- **判決**：超渡最圓滿；她也很適合上王船（她想跟著去找那些人）。

### 案四：散播熱病的疫鬼（該斬的一件；相當於第一章的阿標）
- **白天**：七境頭的巷子裡，好幾戶人家發燒；一個戴斗笠、看不見臉的影子在門口吹氣。
- **真相**：牠是跟著外地漁船來的疫鬼，專挑迎王期間人多的時候散病，還想躲上王船之外的船逃走。
- **證據**：診所醫生的話（發燒的都在同一條巷）、巷口被踩爛的香、疫鬼身上的鹹魚腥味（物證）。
- **判決**：斬（戾氣 +1）、押送、**上王船**（這正是王船的本意：把疫鬼帶走，最合適）。

## 7. 最後一戰：送王（護送王船）

- **目標不同**：不是打倒魔王，而是**守著王船走到沙灘**（進度條＝王船離海邊多遠）。王船被拖住就走不動。
- **陣形**：沿用前後排；王船在神轎旁邊，前排擋住從海裡爬上來的「黑潮」觸手與小疫鬼。
- **魔王「黑潮」**：一團黑色的海水，裡面有人的臉。牠會「捲浪」（預告後衝上岸，像石駒的衝鋒）。
- **陣前審問（自動出示）**：王船走到三分之一、三分之二、岸邊時各一次；證據對了，黑潮的臉一張張安靜下來。
- **結局判決**：
  - **一起送走**（需要海伯收編或蔡嫂到場）：黑潮跟著王船出海，船員終於回家。
  - **鎮回海裡**：王船送出去了，但海裡還有東西。
  - **斬**：戾氣 +1，記遺憾。
