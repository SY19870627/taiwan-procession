## 0. 取材重點（真實祭典，已查證）

- 迎王是三年一科的祭典，迎接「代天巡狩」的五位千歲爺巡狩地方，**驅除瘟疫與孤魂野鬼**。
- 地方大廟（東隆宮，主祀溫府千歲）在祭典期間改稱「代天府」，作為千歲爺的行館；溫王爺是祭典的領導者，遶境前導、過火開路。
- 程序：七角頭抽籤分職務 → 造王船 → 請王（海邊請水）→ 過火 → 遶境祈福 → 遷船遶境（王船上岸「陸上行舟」）→ 宴王 → **送王（燒王船）**。
- 王船的作用是送走千歲爺，**同時把鎮上的邪煞、疫鬼一併帶走**。送王時王船推到沙灘，四周堆滿金紙、米包與替身，道長開出通往外海的水路，再點火。

## 4. 本章專屬：判決「上王船」

- 夜審多一個判決：**上王船**——不審了，讓牠跟著王船出海。
- 任何鬼都可以上王船（不用查明），**不加戾氣**；但牠的冤情沒解，信徒錄記「隨船走了」（不算圓滿也不算遺憾）。
- 上王船的鬼越多，王船越重：**最後一戰王船走得越慢**（要守更久）。
- 用意：給玩家一個「不斬、也不必全部查清楚」的出口，但有代價。

## 6. 案子（四個鬼）

### 案一：抓著斷舵的老船長「海伯」（主線，接最後一戰；相當於第一章的阿福）
- **白天**：港口最邊邊的繫船柱旁，一個老人雙手抓著一截斷掉的舵，望著海。
- **真相**：三年前那場颱風，是他堅持出海，船沉了，船員都沒回來（蔡嫂的丈夫是其中一個）。他自己被沖上岸，隔年病死。他說「海是吃人的」，其實是不敢面對自己。
- **證據**：蔡嫂的話（「那天船長說最後一網」）、斷舵上刻的船名、港務的舊報紙、黃總理說的颱風那年。
- **判決**：收編→最後一戰他能喊船員的名字（說動黑潮）；超渡→技能；上王船→跟船走。

### 案二：宿舍外的外籍船員「阿迪」
- **白天**：船員宿舍外，一個年輕人坐在冰櫃上，手裡捏著一封沒寄出的信。
- **真相**：他在海上出事，船東沒有通報，他家鄉的家人到現在還在等他寄錢回家。他不是作祟，只是一直把宿舍的燈弄閃，想讓人注意到那封信。
- **證據**：阿娟的話、宿舍的值班紀錄、信封上的地址。
- **判決**：查明＋阿娟傳話→信寄出去（超渡）；這一件**斬了算斬錯**。
- 語氣：寫他的思念與等待，不寫事故細節，不指涉真實國籍以外的刻板印象。

### 案三：偷米包的孤魂「米婆」（溫暖、罪很小）
- **白天**：王船廠堆米包的地方，一個瘦小的老婦人每晚偷一包米。
- **真相**：她生前是港口煮飯給船員吃的，死後沒人祭祀。她偷米不是自己吃，是放在港口給「沒回來的那些人」。
- **證據**：洪師傅（米包每晚少一包）、港口繫船柱下的一碗生米、黃總理（以前港口有個煮飯的阿婆）。
- **判決**：超渡最圓滿；她也很適合上王船（她想跟著去找那些人）。

### 案四：散播熱病的疫鬼（該斬的一件；相當於第一章的阿標）
- **白天**：七境頭的巷子裡，好幾戶人家發燒；一個戴斗笠、看不見臉的影子在門口吹氣。
- **真相**：牠是跟著外地漁船來的疫鬼，專挑迎王期間人多的時候散病，還想躲上王船之外的船逃走。
- **證據**：診所醫生的話（發燒的都在同一條巷）、巷口被踩爛的香、疫鬼身上的鹹魚腥味（物證）。
- **判決**：斬（戾氣 +1）、押送、**上王船**（這正是王船的本意：把疫鬼帶走，最合適）。

## 7. 最後一戰：送王（護送王船）

- **目標不同**：不是打倒魔王，而是**守著王船走到沙灘**（進度條＝王船離海邊多遠）。王船被拖住就走不動。
- **陣形**：沿用前後排；王船在神轎旁邊，前排擋住從海裡爬上來的「黑潮」觸手與小疫鬼。
- **魔王「黑潮」**：一團黑色的海水，裡面有人的臉。牠會「捲浪」（預告後衝上岸，像石駒的衝鋒）。
- **陣前審問（自動出示）**：王船走到三分之一、三分之二、岸邊時各一次；證據對了，黑潮的臉一張張安靜下來。
- **結局判決**：
  - **一起送走**（需要海伯收編或蔡嫂到場）：黑潮跟著王船出海，船員終於回家。
  - **鎮回海裡**：王船送出去了，但海裡還有東西。
  - **斬**：戾氣 +1，記遺憾。

## 10. 神明的差異（已確認、已實作）

操作方式和第一章一樣，但神明不同，辦事的方式也不同。

**取材（查證過的事實）**
- 代天巡狩的千歲爺源自明清的巡按制度；巡按的職責包括「審錄罪囚、吊刷案卷」。
- 迎王的本意是送瘟：王船載走瘟疫與邪煞，送王時燒掉。
- 中軍府是千歲爺的屬官，迎王時有自己的神轎；轎班以轎衫顏色區分所屬的千歲（中軍府為白色）。

**設計（遊戲的推演，不是真實儀式）**
- 「調閱案卷」的夜審、「押煞上船」的小妖處理、「五王火」「王令」兩個法術，都是遊戲依上面的事實推演出來的，不是東港實際的儀式。

| | 第一章 青嶺王（萬舺） | 第二章 雲王爺／代天巡狩千歲（東津） |
|---|---|---|
| 白天的小妖 | **驅散**：花 1 時辰，八將打散 | **押煞上船**：不花時辰，用王令（每天 2 道），小妖自己走上王船 |
| 收容的地方 | 令旗下 | 王令下 |
| 夜審 | 文武判官**審問供詞**：追問、在疑點句出示證據 | 中軍府呈上**案卷**：記載有塗改、缺頁、模糊；**塗改用物證、缺頁用文獻、模糊用證詞**補正；「記載無誤」的那一筆不用補 |
| 出示錯了 | 怨氣 +1 | 案卷「駁回」，怨氣 +1 |
| 判決 | 化解超渡、收編、押送地府、斬（阿標可放走） | **上王船**、超渡、**留府當差**（＝收編）、**行刑**（＝斬） |
| 最後一戰 | 喚回石駒：打到煞氣歸零 | **送王**：護送王船走到沙灘（進度型） |
| 主神法術 | 天令（雷擊）、淨符（回血） | **五王火**（前排前方燒起火牆 5 秒）、**王令**（押走拖船的觸手；沒有觸手就押最近的妖怪） |
| 超渡換來的技能 | 回春符、寒霜令、鎮煞鈴 | **定風旗**（海伯：打斷捲浪）、**順風令**（阿迪：王船 6 秒兩倍快）、**平安米**（米婆：全隊回血） |

**上王船的代價**：不加戾氣，但每上一個鬼，王船重一些（最後一戰走得慢 8%）。疫鬼如果沒補正第 3 筆（牠其實想躲回海昌號），送王那晚會跳船（小妖多 2 波）。

**最後一戰（送王）的打法**
- 王船在左，陣頭在中間，黑潮在右邊的海裡（打不到）。
- 觸手每 10 秒從沙裡伸出一隻（最多 3 隻），每一隻讓王船慢 40%；前排沒人時，觸手直接勒王船。
- 黑潮會「捲浪」：浪頭升起 2.5 秒預告，然後打上岸，撞前排所有人；前排沒人就打王船、往回推一段。之後退潮 4 秒，王船走得快。
- 陣前審問在王船走到 1/3、2/3、快到岸邊時：①「岸上的人早就忘了我們」（繫船柱下的米、蔡嫂說的阿婆，或請米婆上前）②「是船長害的」（港務舊報紙、颱風舊聞、蔡嫂的話）③ 只有人說得動：海伯（留府當差）或蔡嫂（第三天邀請）。
- 結局判決：一起送走（需要第 3 輪說動）、鎮回海裡、斬。
- 陣頭：中軍府轎班（令牌拉小妖）、大千歲轎班（肉盾）、三千歲轎班（震轎，觸手最怕）、鹽米隊（遠程緩速）；阿城扛前槓的話多七境頭轎班；黃總理請到小琉嶼船隊護航（交陪）；留府當差的阿迪、米婆、疫鬼（瘟差）上場。

**平衡（模擬）**：只按法術不換位會輸；不放法術（王船一直被拖住）會輸；換位＋法術可以贏；準備充分很穩；四個鬼全上船又審問全錯會輸。

**以後的武神章節（構想）**：小妖直接斬殺（省時辰，但戾氣上升更多）；夜審改為「點將問罪」（比較快、真相層數較少）。
