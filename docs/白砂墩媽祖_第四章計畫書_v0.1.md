## 3. 主題與核心賣點

前三章玩家手上有令旗、王令、乾坤圈，路怎麼走是玩家選的。這一章反過來：**路不是你選的**。轎子在路口頓一下、轉進去，你只能跟。

所以這章的玩法只有一件事：不知道下一步往哪走的時候，你怎麼把後面那一長串人顧好。

賣點有兩個。第一個是「猜」。轎子不是亂走的。前一晚誰在轎前哭過、誰家在哪條路上，有在聽信徒講話的玩家會猜到七八成；猜不到的那幾次，事後才知道為什麼轉那裡。賢仔車行就是這樣：轉進去的時候沒人懂，到了夜裡才知道那塊地以前住著誰。

第二個是「人多」。第一天是海線小路上一小隊人，第三天整條省道都是。人一多，要辦的事一定比時辰多，「神明很忙顧不完」在這章會從一句主題變成畫面上看得到的東西。但人多也有回報：你第一天幫過的人，第三天會出現在點心站幫別人。

三條不能破的線，直接當設計限制寫死：

- 轎、頭旗、香擔在畫面上不是可以點的東西。玩家的兵馬不碰，妖怪也碰不到，牠們只能對落隊的人下手。
- 行轎沒有任何玩家輸入。玩家能做的是「先把兵派去哪邊等」。
- 香擔的火在任何結局都不會熄。最壞的結局是有人沒跟上。

## 4. 核心玩法：三個方案

### 方案 A「跟轎」：押路、跟路

每天的結構從「pre → 玩家二選一 → post」改成「pre → 行轎岔路 → 停駕點 → post → 駐駕」。

到岔路口前，玩家看得到甲、乙兩條路各有什麼（哪邊有小妖、哪邊有人在等），然後決定先鋒兵馬放哪：

| 選擇 | 轎子真的走那邊 | 轎子走另一邊 |
|---|---|---|
| 押甲／押乙 | 那條路的小妖已經清掉，省 1 時辰 | 兵馬要趕回來，少 1 時辰 |
| 留在轎邊 | 不賺不賠 | 不賺不賠 |

轎子走哪邊由內容決定（當天哪位信徒的故事線在哪條路上），不是亂數。線索藏在前一晚的夜審和白天的問話裡。每天另有一次「臨時轉進」：甲乙都不是，轎子拐進第三個地方，這次沒得猜，只有事後的解釋。

- 爽點：猜中的時候很像真的香燈腳在路口說「我就知道會彎這裡」。猜錯也不會死，只是手忙腳亂。
- 風險：玩家可能覺得「被劇本牽著走」。所以線索一定要給夠，第一天的岔路要讓人幾乎猜得到。
- 程式：`DayPlan` 要加新的岔路型態（方向由內容給、玩家只押注）、多一個停駕點節點；`ImpRule`、`TrialStyle`、`BattleMode` 各新增一種。這是三個方案裡動到結構最多的，也是 research-repo §4 預告的那一刀。

### 方案 B「顧隊伍」：頭、中、尾

路線照舊固定，重點放在隊伍長度。隊伍分頭、中、尾三段，玩家每個時辰決定兵馬守哪一段，小妖專挑沒人守的那段。

- 爽點：調度感強，人多的壓力很直接。
- 風險：很容易做成「隊尾安全度」之類的條，等於把 10-26 拿掉的數值換個名字加回來。而且路線不可預測這個最大特色沒用到。
- 程式：路線結構不動，多一層隊伍分段的狀態和 UI，中等。

### 方案 C「傳消息」：今天拍到什麼，明天來什麼人

路線照舊固定。每天日落，玩家從當天辦過的事裡挑一件「讓跟轎台剛好拍到」，決定明天湧進來的是哪種人，明天的事件牌組跟著換。

- 爽點：直接接上 10-27 的「宣傳」；選擇跟後果隔一天，看得到因果。
- 風險：只有這個的話，白天玩起來跟前三章差不多。
- 程式：最少。事件池加標籤、日落多一個選擇畫面。

### 推薦：A 當骨架，把 C 縮成每天一次的選擇併進去

理由很簡單：出巡圖上那句簡介寫的是「往哪裡走，只有媽祖知道」和「跟上來的人一天比一天多」，A 管前半句，C 管後半句。B 的隊伍分段不做成系統，只留成畫面（隊伍越拉越長）和小妖的行為（專找隊尾）。

併進去之後，日落的選擇長這樣，代價照例明講：

| 讓阿哲拍到 | 明天多來的人 | 明天的代價 |
|---|---|---|
| 轎子在車行過夜 | 看熱鬧的年輕人 | 多 2 件小事（鞋子、中暑），多 1 攤點心站 |
| 秀枝推輪椅跟在隊尾 | 帶病人來求的家屬 | 多 2 件很難辦的事，沒有多的幫手 |
| 什麼都不拍 | 沒有多的人 | 明天清閒，但第三天過溪時少一批會牽人的手 |

### 最後一戰：渾水溪・茫渡（`ford`）

轎子先過去了，霧裡只剩對岸一點粉紅色。戰場上沒有轎、沒有香擔，只有還在水裡的隊中和隊尾。

- 茫渡起霧、學人講話，把人往下游的沙洲帶。牠不打人，牠是要留人。
- 玩家照舊前後排換位、法術冷卻；收編的鬼可以上場（帶錯歸處的鬼不會來）。
- 新東西是「人鏈」：前兩天被你幫過的信徒會下水牽人，幫過幾位就有幾段。這是 C 方案在最後的回收。
- 陣前審問三輪（70／40／10%）問出牠是誰：以前在這裡擺渡的。橋蓋好以後沒人坐船，也沒人記得溪底還有一個。
- 結局判決：喚回（留在溪邊當引路的，明年過溪有人帶）／送回（送上對岸，了了）／斬。
- 遺憾結局：有幾個人被帶到下游，天亮在沙洲上找到，人沒事，但沒趕上回宮。黃曆「昨日」欄會寫他們的名字。

轎子為什麼不走橋，過場最後由兵馬自己講出來，不由旁白替媽祖解釋。

## 11. 請你決定的事

**Q1 玩家這章是誰？**
選項：(a) 頭旗下的無形兵馬領隊；(b) 跟前三章一樣的視角，只是把「選路」拿掉。
