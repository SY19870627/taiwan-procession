# 第四章「白砂墩・媽祖徒步進香」開爐黃曆頁（kailu4，回宮第 12 天）

（註：接在 ch4-text-day3.md 第 9 節開爐收尾之前。格式照前三天的黃曆頁。）

- lunar：【待定】三月二十
- yi：【待定】開爐　搓圓
- ji：【待定】空腹
- source：【待定】白砂墩拱辰宮誌・卷三
- text 第一段：【待定】進香回來，神龕的布幔先放著，香擔的封條也不撕，等十二天。第十二天開爐，庄裡家家搓湯圓挑到廟口，紅的白的倒在一起，煮成一大鍋。
- text 第二段：【待定】今天開爐。殿裡站不下的，站到廟埕。湯圓煮了很多，自己舀。
- （註：第一段是舊聞口吻，不當證物用。第二段不提誰有沒有趕上，各結局通用。）
