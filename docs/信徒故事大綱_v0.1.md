# 信徒故事大綱 v0.1（原型：青嶺王暗訪）

> 狀態：草案，待審。審過後才實作。
> 建立日期：2026-10-25
> 取代：GDD 第 5 章（白天祈福）、第 10 章（事件系統）、第 15 章（妖怪視角過場）的原型內容。

---

## 0. 這份大綱要解決的問題

試玩後的回饋：

1. 過場對話沒有前因後果，像湊數，不如拿掉。
2. 一開場就是一條長龍在路中間跑進度條，會立刻想跳過。
3. 白天缺少互動，選項只是加減數值。

改版的核心一句話：

> **神明很忙，顧不了每個人。**
> 白天的時辰有限，每條路、每次停轎、每一次要不要顯現神蹟，背後都是一個真實的信徒。

## 1. 設計原則

| 原則 | 說明 |
|---|---|
| **選擇一律明講** | 每個選項事先寫清楚：花多少時辰與香火、幫了得到什麼、不幫會怎樣、期限到什麼時候。玩家不用猜。 |
| **張力來自取捨，不是資訊不足** | 玩家清楚看到兩邊都有人在等，但只能去一邊。 |
| **沒有一條路救得了所有人** | 一次遊玩不可能讓每位信徒都圓滿，這就是重玩的目標。 |
| **神蹟稀少且有代價** | 一天最多一次（第三天兩次）；用了當晚會更危險。 |
| **情報解鎖更好的選項** | 判官審出的情報不是揭露隱藏真相，而是多出便宜、有效的新選項。 |
| **失敗的上限是「遺憾」** | 不寫死亡，尤其孩子的故事。壞結局是「大病一場」「收掉老店」「從此不敢說」。 |
| **對話只留推動劇情的** | 拿掉小妖搞笑過場。故事改由黃曆頁、信徒卡、結局「信徒錄」來說。 |

## 2. 每天的流程

```
黃曆頁（故事＋宜忌）→ 選路線 → 沿路停轎、處理信徒卡（花時辰）→ 黃昏 → 布陣 → 夜戰 → 天亮審判
```

### 2.1 黃曆頁

- 每天開頭翻開一頁泛黃的舊黃曆：直書、紅色日期、宜忌、沖煞。
- 右半頁是一段**廟誌或地方舊聞**的文字，用來說故事，有歷史感。
- 下方的「昨日」欄寫出前一天沒照顧到的信徒發生了什麼（第二天起）。
- 宜忌與當天的玩法有關，但信徒卡上一定會再明講，不靠玩家自己解讀。

### 2.2 時辰

- 一天從辰時走到申時，共 **5 個時辰**（第三天要會香，只有 **4 個**）。
- 停轎處理一位信徒：1～2 個時辰（卡上寫明）。
- 移動不另外花時辰（隊伍行走只是兩站之間幾秒的過場，可跳過）。

### 2.3 路線

- 每天在街區地圖上有 **2 條路線**，並排顯示沿途每一站的信徒卡摘要與時辰總數。
- 選一條走。另一條路線上的信徒今天就沒人照顧。
- 同一條路線上，時辰不夠時也要取捨要停哪幾站。

### 2.4 信徒卡（每一站都有）

```
┌─────────────────────────────────────┐
│ 阿秀嬸・菜市場                    期限：明日黃昏 │
│ 孫子阿弟夜夜啼哭、發燒不退。                      │
│                                                     │
│ ▸ 收驚　　1 時辰・香火 5                          │
│   孫子當晚退燒。阿秀嬸在市場幫忙號召：信徒 +6     │
│ ▸ 顯現神蹟　神蹟 1 次・香火 20・今晚妖怪 +2 波    │
│   （今天不需要，收驚就夠）                        │
│                                                     │
│ 不處理：明天病情加重，只剩神蹟或「鹽米」能救       │
└─────────────────────────────────────┘
```

- 卡上永遠寫明：**選項、花費、結果、不處理的後果、期限**。
- 需要特定情報才出現的選項，會以灰色顯示並註明解鎖條件（例如「需要情報：小魍怕鹽米」）。

### 2.5 神蹟

| 項目 | 內容 |
|---|---|
| 次數 | 第一、二天各 1 次，第三天 2 次 |
| 花費 | 香火 20 |
| 好處 | 立刻解決最嚴重的狀況；目睹神蹟的凡人大量加入（信徒 +8～12） |
| 代價 | **天機外洩**：當晚妖怪多 2 波，且從神轎正面來襲 |
| 顯示 | 選項上直接寫出代價，例如「今晚妖怪 +2 波（正面）」 |

### 2.6 因果簿

- 隨時可以打開的清單，列出：
  - 還沒處理的信徒、各自的期限
  - 已經發生的後果
  - 會影響今晚、第三夜的效果（例如「石駒受傷暴怒：衝鋒更頻繁」）

## 4. 三天的內容

### 序章（標題畫面之後，不能操作的部分控制在 30 秒內）

**黃曆頁・農曆十月十九**

> 萬舺青嶺宮誌・卷三
> 每歲十月二十、二十一，王爺夜巡，謂之暗訪。七爺八爺前導，捕陰陽二界作祟者；文武判官隨後，鞫之於廟。凡人但見燈火鑼鼓，不知其戰。
> 是歲十九夜，宮中香爐之香，無風自斷者三。

阿土伯（一句）：「香斷了三次……王爺有話要說。」

→ **第一個操作：擲筊請示**「明日是否照常暗訪？」
（不論結果都會出巡；差別只在起駕時的士氣與香火，選項上寫明三種結果。用來教玩家擲筊。）

### 第一天・農曆十月二十・萬舺

**黃曆**：宜　祭祀、出行／忌　動土
**舊聞**：
> 萬舺舊為番社渡口，商船輻輳。老輩言，街市愈旺，陰陽二界之物愈雜。

**路線**

| 路線 | 沿途 | 時辰 |
|---|---|---|
| **甲・市場線** | 菜市場（阿秀嬸）→ 冰果室（阿哲）→ 布莊（小事） | 1 + 2 + 1 = 4 |
| **乙・學校線** | 國小門口（小芸）→ 老人會（小事）→ 河岸小魍巢 | 1 + 1 + 2 = 4 |

剩下的 1 個時辰可以在路線終點的廟口「上香祈福」（香火 +5），或省下來讓黃昏提早布陣（士氣 +5）。

**信徒卡**

| 地點 | 狀況 | 選項 | 不處理的後果 |
|---|---|---|---|
| 菜市場・阿秀嬸 | 孫子夜啼發燒（期限：明日黃昏） | 收驚（1 時辰、香火 5）→ 退燒，信徒 +6 | 第二天病情加重 |
| 冰果室・阿哲 | 嫌鞭炮吵、要隊伍改道 | ①低調繞過（1 時辰）→ 無事；②顯現神蹟（2 時辰）→ 他親眼看到七爺八爺擋下撲向他的小魍，當場信了，信徒 +10；今晚妖怪 +2 波 | 第三天冰果室傳出要收掉 |
| 布莊 | 老闆娘請隊伍停下來拜一拜 | 停轎（1 時辰）→ 香火 +10 | 無 |
| 國小門口・小芸 | 一直盯著七爺看，同學笑她「說謊精」 | 讓八爺給她一張平安符（1 時辰）→ 她記住了隊伍，信任 +1 | 第二天她被小魍跟回家，處理會更麻煩 |
| 老人會 | 長輩們想看醒獅 | 表演（1 時辰）→ 士氣 +10 | 無 |
| 河岸・小魍巢 | 小魍聚集的地方 | 先清巢（2 時辰）→ 今晚妖怪 -2 波 | 無 |

**夜：第一夜・暗訪**（現有戰鬥）
**天亮審判**：捉到 2 隻以上 → 情報「小魍怕鹽米」（解鎖：阿秀嬸、小芸的便宜選項）

### 第二天・農曆十月二十一・萬舺 → 芝林

**黃曆**：宜　解除、祈福／忌　狩獵　**日沖馬**
**舊聞**：
> 芝林舊聞
> 芝嶺巖有石，狀如馬。相傳昔為開疆聖王坐騎，隨王征戰。後聖王他往，駒獨留山中，夜出食禾稼。莊人鑿其腹，駒乃不動，化為石。

**昨日欄**（依第一天結果）：例如「菜市場的阿秀嬸沒等到隊伍。阿弟燒到昏睡，今早被送去診所。」

**路線**

| 路線 | 沿途 | 時辰 |
|---|---|---|
| **甲・大路線** | 診所（阿秀嬸，若未解決）→ 小芸家 → 龍嶺寺前 | 2 + 1～2 + 1 = 4～5 |
| **乙・河堤線** | 芝林菜園（阿雄）→ 石材行（林伯） | 2 + 2 = 4 |

**這一天是整個原型最難的取捨**：甲線救的是眼前的人（阿弟、小芸），乙線是在為第三夜做準備（阿雄、林伯）。卡片上都寫得清清楚楚，但時辰只夠走一條。

**信徒卡**

| 地點 | 狀況 | 選項 | 不處理的後果 |
|---|---|---|---|
| 診所・阿秀嬸（第一天沒處理才出現） | 阿弟高燒昏睡（期限：今日黃昏） | ①顯現神蹟（2 時辰）→ 當場退燒，阿秀嬸逢人就說，信徒 +12；今晚妖怪 +2 波　②撒鹽米驅魍（需情報；1 時辰、香火 5）→ 退燒，信徒 +6 | **遺憾**：住院一週，阿秀嬸從此不讓孫子晚上出門 |
| 小芸家 | 第一天見過：晚上被小魍跟回家，很害怕／第一天沒見過：媽媽以為她生病了 | 見過：安符（1 時辰）→ 保護成功，信任 +1；沒見過：收驚＋安符（2 時辰）→ 保護成功 | 她從此不敢說自己看到什麼 |
| 龍嶺寺前 | 寺方請青嶺王停轎會香 | 停轎（1 時辰）→ 香火 +15 | 無 |
| 芝林菜園・阿雄 | 菜被啃光，地上有大蹄印，他說要上山「抓那頭畜生」（期限：今日黃昏） | 祭解並勸阻（2 時辰、香火 10）→ 他放棄上山；告訴你蹄印都從北邊來（今晚預知妖怪方向） | 他上山設捕獸夾：第三夜石駒腿傷暴怒，衝鋒更頻繁 |
| 石材行・林伯 | 老石匠一邊磨石一邊看著隊伍 | 聽他說石駒的事（2 時辰）→ 情報「石駒肚子上的舊傷」（魔王戰弱點） | 第三天還有一次機會在山腳遇到他 |

**夜：第二夜・守夜**（現有戰鬥）
**天亮審判**：捉到 1 隻以上 → 情報「石駒衝完會喘很久」

### 第三天・農曆十月二十二・芝林 → 芝嶺巖惠澤宮（正日）

**黃曆**：宜　會友、祭祀、求嗣／忌　出火
**舊聞**：
> 林伯口述（第二天聽過才出現；沒聽過則換成惠澤宮籤詩一首）
> 「那匹馬不是壞東西。牠只是餓，肚子那個洞又一直灌風，冷。」

**昨日欄**：例如「阿雄昨夜沒回家，鄰居在山上找到他，腳被自己的捕獸夾夾傷。」

時辰只有 **4 個**（下午要與惠澤宮會香）。神蹟 **2 次**。

**路線**

| 路線 | 沿途 | 時辰 |
|---|---|---|
| **甲・山腳線** | 山腳（林伯，若沒聽過）→ 山徑（阿雄，若被夾傷） | 2 + 1 |
| **乙・街區線** | 小芸的學校 → 冰果室（阿哲） | 1 + 1～2 |

最後一站固定是惠澤宮：**會香（1 時辰）**→ 結為交陪，令旗隊助陣。可以選擇不會香、省下時辰，但卡上會寫明「失去令旗隊」。

**信徒卡**

| 地點 | 狀況 | 選項 | 不處理的後果 |
|---|---|---|---|
| 山腳・林伯 | 他在等你 | 聽他說（2 時辰）→ 情報「舊傷」 | 魔王戰沒有弱點可打 |
| 山徑・阿雄（第二天沒勸阻才出現） | 腳被夾傷，困在山上 | 救下來（1 時辰）→ 他平安下山；石駒仍然暴怒 | **遺憾**：傷了腳，菜園荒廢一季 |
| 學校・小芸（第二天有保護才出現） | 她說：「那匹石頭馬一直在哭。」 | 邀她黃昏到惠澤宮（1 時辰）→ 魔王戰中她會呼喚石駒，石駒煞氣一開始就少 20%，且第一次衝鋒會停下 | 她只能在家裡擔心 |
| 冰果室・阿哲 | 信了：在店門口擺香案／沒信：門口貼了「頂讓」 | 信了：停轎（1 時辰）→ 他把遶境影片傳上網，信徒 +15／沒信：顯現神蹟（2 時辰、神蹟 1 次）→ 他決定留下老店，信徒 +10；今晚妖怪 +2 波 | 沒信又沒處理：**遺憾**：冰果室收掉 |

**黃昏**：石駒獨白（僅此一段，三句）
> 「我記得鑼聲，記得旗子在風裡響。」
> 「肚子那個洞，冷風一直灌進來。」
> 「你們這些拿旗子的人……也是來鑿我的嗎？」

**夜：第三夜・喚回石駒**（現有戰鬥，加上下表的效果）

| 前面做過的事 | 第三夜的效果 |
|---|---|
| 聽過林伯（或判官審出） | 石駒喘息時打肚子的舊傷，傷害大增 |
| 判官審出「喘很久」 | 喘息時間變長 |
| 阿雄被勸阻 | 石駒正常 |
| 阿雄設了陷阱 | 石駒暴怒：衝鋒更頻繁、傷害更高 |
| 小芸在場 | 煞氣開場 -20%，第一次衝鋒中途停下 |
| 會香結交陪 | 令旗隊助陣 |
| 當天用過神蹟 | 每用一次，妖怪 +2 波 |

**喚回之後**（神明視角，只有兩句）
> 開疆聖王：「回來吧。」
> 石駒：「……主公。」

## 5. 結局：信徒錄

用黃曆紙的樣式，一人一欄，寫出這三天之後每個人的結局。

| 人物 | 圓滿 | 遺憾 |
|---|---|---|
| 阿秀嬸與阿弟 | 「阿弟退燒那天，阿秀嬸在攤子上多送了每個客人一把青蔥。」 | 「阿弟住院一週。出院後，阿秀嬸再也不讓他晚上出門。」 |
| 小芸 | 「後來她在作文裡寫：我看過一匹石頭馬回家。老師給了甲上。」 | 「她從此說，自己什麼都沒看到。」 |
| 阿哲 | 「冰果室的招牌重新漆過。他說，再做十年看看。」 | 「冰果室收了。鐵門上貼著『感謝四十年來的照顧』。」 |
| 阿雄 | 「隔年春天，菜園收成比往年都好。」 | 「傷了腳，菜園荒廢了一季。」 |
| 林伯 | 「他刻了一匹小石馬，送到惠澤宮供著。」 | 「沒有人再來聽他說那匹馬的故事。」 |
| 石駒 | 喚回：「石駒歸隊。」／暴怒中喚回：「石駒歸隊，但腿上的傷，要很久才會好。」 | （夜戰失敗可重來，不列為結局） |

最後一行統計：**「這三天，你照顧了 N / 5 位信徒。」**

## 6. 與現有原型相比，要改的地方

| 項目 | 現在 | 改成 |
|---|---|---|
| 開場 | 妖怪視角對話 → 隊伍直接走 | 黃曆序章 → 第一個操作就是擲筊 |
| 白天畫面 | 橫向捲動＋進度條＋隨機彈出事件 | 街區地圖＋選路線＋停轎處理信徒卡 |

| 結局 | 數字統計 | 信徒錄 |
| 新增 | — | 因果簿 |
| 保留 | 夜戰、布陣、隊伍整備、逐項升級 | — |
