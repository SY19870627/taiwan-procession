## 1. 一句話概念

**你是一位神明。白天，你的進香隊伍沿著台灣一路祈福；晚上，隊伍駐駕的廟埕就是斬妖的戰場——而凡人什麼都看不見。**

## 2. 設計支柱

| 支柱 | 說明 |
|---|---|
| **看不見的戰爭** | 現實的台灣照常運作，山不會動。妖怪活在人看不到的靈界，作亂時在陽間只顯現為「怪事」。 |
| **整支進香隊伍** | 玩家指揮的不是一台車、一頂轎，而是整條隊伍：報馬仔、陣頭、神轎、信徒、後勤。 |
| **白天祈福，晚上斬妖** | 白天收集與準備，晚上自動戰鬥。白天的成果決定晚上的戰力。 |
| **合作，不敵對** | 神明之間不互相為敵。各派系透過「交陪」合作作戰，敵人只有妖怪。 |
| **在地的妖怪** | 妖怪取材自台灣各地有記載的精怪傳說，不只鬼類；每個地區都有自己的魔王。 |
| **出征與經營** | 每次出巡就是一次出征，成果帶回自己的廟持續經營、擴建。 |

## 3. 世界觀

### 3.1 兩層世界

- **陽間**：一般人看到的台灣。上班、上學、夜市照開，山就是山。
- **靈界**：神明與進香隊伍看得到的層次。象形山石中的精魄、在地精怪、孤魂野鬼都在這一層活動。

這個遊戲的世界**全部關於人看不見的東西**。真實的地景不會被破壞或移動，變化只發生在靈界。

### 3.2 開場事件：封印崩壞

台灣各地許多傳說的結局都是「妖怪被制伏，化為山石」。這些山石其實是古時的**封印**。

某一天，守護全島的結界開始崩壞，被鎮壓在象形山石中的精魄一個個甦醒。蟾蜍山的蟾蜍精重新吐毒，鶯歌石的妖鳥又開始吐霧。

### 3.3 妖怪在陽間的「顯現」

妖怪作亂時，凡人看到的只是難以解釋的怪事。這些怪事就是玩家找到妖怪的線索（以新聞跑馬燈、地方傳聞呈現）：

| 靈界的原因 | 陽間看到的怪事 |
|---|---|
| 蟾蜍精吐毒 | 公館一帶不明原因咳嗽、生病 |
| 鶯哥精、鳶精吐霧 | 三峽、鶯歌莫名大霧，登山客迷路 |
| 鯉魚精抓交替 | 蘭潭接連溺水 |
| 魔神仔 | 老人家在山中失蹤 |
| 地牛躁動 | 地震頻繁 |

### 3.4 為什麼要環島

環島的目的是**重新修補全島的結界**。

- 結界由沿海與山中的各廟香火共同撐起。
- 進香隊伍繞台灣一圈，一站一站重燃各地香火、收服甦醒的精怪。
- 最終魔王（建議）：一直被壓在台灣島底下的**地牛**。繞完一圈補好結界，才能把地牛重新鎮住。

> 註：「地牛為最終魔王」是本作的原創設定，並非傳說原有內容。

### 3.5 信仰的力量

神明需要人：人扛轎、人放鞭炮、人上香，信仰才有力量。信徒看不見這場戰爭，卻用「相信」支撐這場戰爭。

在靈界中，陽間的行為都有對應的戰力：

| 陽間 | 靈界 |
|---|---|
| 鞭炮 | 驅邪火力 |
| 鑼鼓聲 | 震妖的音波 |
| 陣頭步伐 | 布陣 |
| 上香 | 香火（神明法力） |

## 4. 核心循環

### 4.1 三層循環

```
【大循環】廟宇經營 ──出巡（出征）──▶ 一段環島路線 ──帶回成果──▶ 廟宇經營
                                         │
【中循環】                       一天：白天祈福 → 駐駕 → 晚上斬妖 → 天亮結算
                                         │
【小循環】                       白天：事件、選擇、收集；晚上：一波波妖怪自動戰鬥
```

### 4.2 一次出巡的流程

1. **出發前（廟內）**：選擇路線、編組隊伍、準備物資。
2. **連續數天的晝夜循環**：每天白天上路，晚上駐駕斬妖。
3. **區域魔王**：抵達該地區的核心，挑戰在地魔王。
4. **回廟**：帶回香火、信徒、法器、聲望，經營自己的廟。

## 6. 晚上：斬妖（靈界）

- **凡人眼中**：隊伍在廟裡休息，轎班睡在香客大樓。
- **靈界中**：**紮營布陣**。神轎坐鎮廟埕，陣頭布在四周，妖怪一波波攻來。
- **全程自動戰鬥**，玩家的決策在於：布陣位置、陣頭組成、法器與神明法術的使用時機（細節待定）。
- **勝利條件**：撐到雞啼天亮。
- **失敗條件**：神轎被攻破（細節待定）。

### 6.1 兩種夜晚型態

| 型態 | 說明 |
|---|---|
| **守夜** | 防守。在駐駕的廟埕撐到天亮。 |
| **暗訪** | 主動出擊。夜巡掃蕩附近的妖怪巢穴，風險高、收穫大。取材自王爺夜巡的「暗訪」傳統。 |

### 6.2 白天成果如何影響晚上

| 白天收集 | 晚上影響 |
|---|---|
| 香火 | 神明法力 |
| 信徒人數 | 守營兵力 |
| 隊伍士氣、體力 | 陣頭表現 |

## 7. 進香隊伍

隊伍依真實進香的順序編排，每個位置各有作用：

| 位置 | 角色 | 作用（初步） |
|---|---|---|
| 最前方 | **報馬仔** | 探路，提早看見前方的事件與妖怪 |
| 前段 | **頭旗、頭燈** | 隊伍門面，提供士氣與加成 |
| 前排／兩側 | **陣頭** | 戰鬥主力（八家將、官將首、宋江陣、跳鼓陣、電音三太子……） |
| 中央 | **神轎** | 核心，必須保護 |
| 中後段 | **香客、信徒** | 人數即香火來源；人越多越容易被側面、後方偷襲 |
| 後段 | **後勤** | 補給車、點心攤、隨香醫護，回復體力與補給 |

- **隊形即戰術**：妖怪會從前方、兩側、後方來襲，陣頭與信徒的位置影響戰局。
- **隊伍會成長**：沿途信徒加入，隊伍越走越長，畫面上看得見。

## 8. 主神與派系

- 主神代表**派系**，每位主神有不同的玩法風格。
- 派系之間**不敵對**，以良性競爭與合作為主（比香火、會香結盟）。
- 所有神明一律設定為守護者，尊重真實信仰。

| 主神 | 風格（初步構想） |
|---|---|
| 媽祖 | 守護與回復，擅長海線，保護隊伍 |
| 關聖帝君 | 武力，強化陣頭攻擊 |
| 玄天上帝 | 鎮煞，對妖怪（獸精）特攻 |
| 王爺 | 驅瘟送煞，王船相關的特殊能力 |
| 城隍爺 | 陰間勢力，夜晚與對鬼類特別強 |
| 土地公 | 經濟，香火產出最高、廟宇經營最強 |

> 待定：開局選擇主神，或固定主神。

## 9. 公廟進駐與交陪（合作作戰）

取材自台灣廟宇之間的「**交陪境**」關係。

- 各地都有被妖怪圍困的**公廟**（角頭廟、庄頭廟）。
- 進香隊伍抵達後**進駐**，與當地神明、陣頭共同守廟（即晚上的守夜戰）。
- 守住之後成為**交陪廟**：
  - 可補給、休息
  - 當地陣頭可加入之後的出巡
  - 當地神明提供加持
- **交陪度**隨合作次數累積，解鎖更多支援。
- **聯合遶境**：交陪度足夠時，可號召多間廟共同出征，對付大魔王。
- **分靈建廟**：收復的鄉鎮可以分靈，成為長期據點，提供香火與補給。全島地圖會從被妖怪佔據，一塊一塊點亮。

## 10. 事件系統（白天）

- **選擇卡**：例如路邊有人求助，選擇幫忙、繞過或請示神明，影響香火、時間、士氣或觸發後續劇情。
- **擲筊**：岔路或重大抉擇時請示神明，聖杯、笑杯、陰杯帶來不同結果。
- **地方怪事**：新聞跑馬燈、地方傳聞，作為妖怪線索。
- **農曆節日**：元宵、迎媽祖、普渡、做醮等特殊事件。

## 11. 妖怪

### 11.1 妖怪類型

| 類型 | 例子 |
|---|---|
| 獸精 | 蟾蜍精、鯉魚精、貓精、老猴精、巨蛇 |
| 禽妖 | 鶯哥精、鳶精 |
| 器物、石妖 | 石馬 |
| 天災妖 | 地牛、落漈漩渦、蝗蟲妖 |
| 鬼類 | 林投姐、水鬼、魔神仔 |
| 原創 | 鯰魚精（台灣無在地記載，作為本作原創） |

不同類型有不同弱點，對應不同陣頭與派系（例：鬼類怕城隍，獸精怕玄天上帝；細節待定）。

### 11.2 區域魔王（取材自台灣在地傳說）

| 魔王 | 地點 | 傳說重點 | 遊戲構想 |
|---|---|---|---|
| 蟾蜍精 | 台北公館（蟾蜍山） | 噴毒害農作、吃人，被制伏化為巨岩；收服版本有呂洞賓、鄭成功等 | 毒霧、持續傷害 |
| 鶯哥精 ＋ 鳶精 | 鶯歌、三峽 | 兩隻妖鳥隔大漢溪互吐迷霧，鄭成功砲擊斷鶯哥頸，化為鶯歌石 | 雙頭目戰，迷霧遮蔽視野 |
| 石馬 | 士林（舊稱八芝蘭） | 原隨開漳聖王出戰，後失控吃農作物，村民鑿其腹制伏 | 衝鋒、高防禦 |
| 鯉魚精 | 嘉義蘭潭 | 都市傳說：潭底鯉魚精率魚兵魚將「抓交替」 | 召喚魚兵 |
| 鯉魚精 ＋ 貓精 | 台東鯉魚山 | 鯉魚精眼睛被挖，山壁留下凹洞 | 東部雙頭目 |
| 落漈 | 台灣海峽 | 吸船的大漩渦 | 澎湖、海線關卡 |
| 怪鱷 | 澎湖 | 1683 年擱淺的巨鱷，被視為明鄭滅亡之兆 | 離島魔王 |
| 地牛 | 台灣島下 | 地牛翻身（地震） | 最終魔王（原創設定） |

### 11.3 難度遞增

- **階級**：小妖 → 精怪 → 厲鬼 → 妖王，越後期越多種類混合出現。
- **距離**：離自己的廟越遠，妖怪越強。
- **煞氣擴散**：未收復的地區會擴散，甚至反攻已收復的地區。
- **適應**：玩家一直用同一種打法，妖怪會長出抗性，逼迫更換陣容。
- **農曆節點**：農曆七月鬼門開，全面暴增，是固定難關。

## 13. 遊戲長度

- 一次出巡只推進一段路、收復一個地區。
- 全島切成數十個鄉鎮級路段，加上分歧路線（山線、海線、蘇花、南迴）。
- 整趟環島是數十次出巡構成的長期戰役。
- 時間軸走過農曆一整年，節日帶來特殊事件。

## 15. 劇情與過場：妖怪視角

- 平常玩家站在神明這一方；**過場切換到妖怪視角**，讓「看不見的戰爭」更立體，也為每晚的戰鬥鋪梗。
- 形式：簡短對話過場（幾句台詞），程式繪製的剪影與對話框，不需要大量美術。
- 語氣：小妖以**詼諧**為主（膽小、愛抱怨、互相推卸）；魔王帶一點**悲涼**（被鎮壓數百年，醒來世界全變了）。

### 15.1 過場時機

| 時機 | 內容範例 |
|---|---|
| 開場 | 蟾頭精在山石中甦醒：「睡了兩百年……這城怎麼變得這麼亮？」 |
| 白天轉黃昏 | 小妖躲在騎樓偷看遶境隊伍，鞭炮一響嚇成一團：「那、那是七爺八爺？手上拿的是……手銬？」 |
| 夜戰前 | 妖怪開會：「今晚不去行不行？」「蟾頭大人說不去就吃掉你。」 |
| 天亮結算 | 被抓的小妖在判官面前受審（見 15.2） |
| 魔王登場／敗退 | 魔王獨白：為什麼甦醒、心裡在想什麼 |

### 15.2 判官審判（劇情與玩法結合）

- 取材自青山王暗訪隊伍中「文武判官負責審判」的傳統。
- 每晚抓到的小妖會在天亮時受審，供詞即**情報**：明晚的妖怪種類、魔王弱點、巢穴位置等。

## 16. 第一個可玩原型

| 項目 | 內容 |
|---|---|
| 取材 | 艋舺青山王祭（台北萬華，主神靈安尊王） |
| 遊戲中名稱 | **萬舺青嶺王祭**（主神靈護尊王，俗稱青嶺王；廟：萬舺青嶺宮） |
| 選擇理由 | 真實傳統中就有「暗訪」：正日遶境前兩晚夜間出巡，捉拿陰陽兩界的妖魔鬼怪；範圍小，適合原型；北部精怪集中 |
| 規模 | 一個地區、三天晝夜循環、一隻區域魔王 |
| 隊伍元素（取材） | 報馬仔、五方旗、引路土地公、七爺八爺（前方捕捉）、文武判官（殿後審判）、八將團、神轎 |
| 區域魔王 | **石駒**（士林，舊稱八芝蘭）。見 16.1 |
| 之後章節 | 大岬遶境進香（取材大甲媽祖遶境：九天八夜，約 340 公里）作為第一個完整長途章節 |

### 16.1 原型魔王：石駒（取材：士林石馬）

**取材（真實傳說，已查證的部分）**
- 地點：士林（舊稱八芝蘭）。
- 石馬原本隨開漳聖王出戰，後來失控，跑去吃農作物；村民在牠肚子上鑿洞，才把牠制住。
- 士林芝山岩上的惠濟宮主祀開漳聖王。

> 待查證：石馬目前的實體位置（是否在惠濟宮）。原傳說涉及漳泉械鬥，本作不採用械鬥情節。

**遊戲構想**
- 石駒不是天生的妖，而是**走偏的神獸**：封印崩壞、煞氣入體，讓牠失控。
- 魔王戰的目標從「打倒」改為**「喚回」**：削弱煞氣後，讓牠認回主人。
- 與交陪系統結合：隊伍進駐芝嶺巖惠澤宮，與開疆聖王**合作作戰**，喚回祂的坐騎。
- 喚回之後，石駒可加入隊伍成為戰力（原型的獎勵）。
- 戰鬥特色：衝鋒、高防禦；肚子上的舊傷（鑿洞處）是弱點。
- 妖怪視角：石駒的獨白帶悲涼感——牠記得自己曾經是神明的坐騎，卻不記得怎麼回去。

### 16.2 原型三天（草案）

| 天 | 白天（陽間） | 晚上（靈界） |
|---|---|---|
| 第一天 | 從萬舺青嶺宮起駕，沿萬舺街區祈福 | 暗訪：七爺八爺捉拿小妖，判官審出「北邊有匹發狂的石駒」 |
| 第二天 | 往北行，沿途怪事：芝林一帶菜園一夜被啃光 | 守夜：石駒的煞氣引來大批小妖攻廟 |
| 第三天 | 抵達芝嶺巖，與惠澤宮開疆聖王會香 | 魔王戰：兩廟聯手，喚回石駒 |

> 註：萬舺到芝林的實際路線與遶境範圍不同，這是遊戲改編。

### 16.3 隊伍整備（逐項升級）

- 白天按「隊伍整備」或直接點隊伍裡的神轎、陣頭；布陣畫面按「整備」「神轎整備」，都會打開整備畫面。
- 一次看一位成員：左邊大立繪，右邊介紹、特性標籤與各項屬性；左右箭頭、滑動或點下方分頁切換。
- 每項屬性分開升級（Lv1–5），花費＝基本價 × 目前等級；畫面同時顯示「現在 → 下一級」的實際數值。

| 神轎 | 轎身（耐久）、天令（雷擊傷害）、淨符（回復比例） |
