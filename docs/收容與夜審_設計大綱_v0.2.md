# 收容與夜審 設計大綱 v0.2（原型：青嶺王暗訪）

> 狀態：**草案，待審**（2026-10-26）
> 取代：信徒故事大綱 v0.1 的「夜戰」部分；白天的取捨精神保留，畫面與內容改版。
> 沿用：黃曆頁、因果簿、信徒錄、判官審判畫面、對話框、直式畫面。

---

## 0. 為什麼要改

試玩回饋：後面的戰鬥不好玩，像換皮遊戲。

原因：

1. 夜戰裡玩家幾乎沒有決定：布陣只選左右，戰鬥中只等冷卻按兩顆鈕。
2. 白天「神明很忙」的主題到了晚上就消失，只剩血條互扣。
3. 妖怪只是數值；它們的傳說沒有變成玩法。

改版的核心一句話：

> **神明管的是人，也是鬼。**
> 白天沿路收容流落的鬼怪，晚上升堂夜審。鬼也有冤情，查清楚了才知道該渡、該收、還是該斬。

## 1. 已確定的方向（2026-10-26 討論）

| 項目 | 決定 |
|---|---|
| 白天畫面 | 回到**隊伍畫面**（隊伍沿街前進），不打仗 |
| 白天玩法 | 多次選擇與取捨：**辦人的事要花時間，抓鬼也要花時間**；路上遇到的鬼怪也要考慮 |
| 晚上玩法 | **夜審**：透過對話查冤屈、查做了多少惡、化解仇恨；無法原諒的可以直接斬 |
| 對質深度 | **中等**：可以追問，也要在對的時候拿出白天得到的證據，抓出矛盾 |
| 戰鬥 | 只剩每次出巡的**最終目標（魔王戰）**；要打也要審 |
| 魔王戰陣形 | 不分前後左右；所有部隊都會攻擊，近戰衝上去打，遠程在後面 |
| 成長 | 沿路各方的小故事累積實力，**取代廟宇經營**；前面累積的成就決定最後一戰 |
| 案子的沉重程度 | 可以寫亡者的過去，不寫血腥細節；語氣接近民間故事，不是恐怖片 |

## 2. 一次出巡的流程

```
黃曆頁 → 白天：隊伍出巡（處理人、收容鬼、查線索）
       → 晚上：夜審（審收容的鬼，下判決）
       →（重複三天）
       → 最後一夜：魔王戰（打＋審）→ 信徒錄
```

| 天 | 白天 | 晚上 |
|---|---|---|
| 第一天 | 萬舺市場、河岸 | 夜審 |
| 第二天 | 萬舺 → 芝林 | 夜審 |
| 第三天 | 芝林 → 芝嶺巖惠澤宮 | **魔王戰：喚回石駒** |

第一、二夜不再有戰鬥。

## 3. 白天：隊伍出巡

### 3.1 畫面（直式）

- **上方**：隊伍沿街前進的橫向畫面（沿用夜戰的戰鬥帶做法）。路邊會出現人、鬼、異象。鬼只有神明看得見，畫成半透明，旁邊的凡人照常生活。
- **下方**：「前方」清單，列出**接下來這一段路**會遇到的事，每一件寫清楚花費與結果。玩家可以先看到前面有什麼再決定，不用瞎猜。
- 隊伍走到一件事前面時停下來，玩家決定處理或略過；略過就走過去了，不能回頭。

### 3.2 時間

- 一天 6 個時辰（第三天 4 個）。
- 隊伍行走本身不花時辰；**停下來做事才花**。
- 一天大約會遇到 9～12 件事，時辰只夠處理一半左右。

### 3.3 路上會遇到的事

| 種類 | 例子 | 花費 | 說明 |
|---|---|---|---|
| **人** | 阿秀嬸的孫子發燒 | 1～2 時辰 | 跟 v0.1 的信徒卡一樣：選項、結果、不處理的後果、期限都寫明 |
| **鬼（收容）** | 古井邊蹲著一個穿大襟衫的女人 | 1 時辰＋收容格 1 | 由七爺八爺帶回令旗下，晚上審 |
| **小妖（驅散）** | 一群小魍在偷香火 | 1 時辰 | 當場驅散，不用審；不處理會小損失（香火、信徒） |
| **線索** | 古井鐵蓋下有一個沒人認的小香爐 | 0～1 時辰 | 得到**證據**，晚上對質用 |
| **問話** | 跟布莊老闆娘聊早年的事 | 1 時辰 | 得到**證詞**，晚上對質用 |
| **岔路** | 往市場或往河岸 | 0 | 一天 1 次，選一邊，另一邊今天就錯過 |

### 3.4 收容

- 令旗下的**收容格**：3 格。
- 收了的鬼，晚上才能審。收不下的鬼今晚繼續作祟（卡上寫明會怎樣）。
- 收容的鬼有**怨氣**（0～3）。每過一夜沒審，怨氣 +1；到 3 會掙脫，跑回去作祟，而且更難審。

### 3.5 取捨的來源

同一段路上常常同時出現：

- 一個有期限的**人**（今天不處理會出事）
- 一隻有冤情的**鬼**（收了才能審，不收它繼續害人）
- 一條**線索**（不拿，晚上審的時候少一張牌）

時辰只夠做其中一兩件。這就是「神明很忙」。

## 4. 晚上：夜審

### 4.1 場面

青嶺宮內，文判官、武判官兩旁，七爺八爺押著收容的鬼。玩家是王爺，主持審問。

### 4.2 一晚能審幾隻

- 一夜分 **3 更**，審一隻花 1 更。收容格滿的時候，一定有一隻要等到明天（怨氣 +1）。

### 4.3 審問的流程（中等深度）

1. **供詞**：鬼先說它的說法，分成 3～5 句。
2. **追問**：點任一句可以追問，鬼會多說一點（有時說溜嘴，出現新的供詞）。
3. **出示證據**：在某一句供詞上，拿出白天得到的證詞、物證或文獻。
   - 對了：戳破謊話或補上被隱瞞的事，揭開一層**真相**。
   - 錯了：鬼起疑、怨氣 +1（不會直接失敗，但有代價）。
4. 每個案子有 2～3 層真相。畫面上會顯示「已查明 1／3」，玩家知道還有沒查清楚的地方。
5. 查到一個段落，玩家可以隨時**下判決**。

### 4.4 判決

| 判決 | 條件 | 結果 |
|---|---|---|
| **化解超渡** | 冤情查明 | 鬼放下執念去投胎；牽連到的活人得救；香火、信徒增加 |
| **收編** | 鬼願意贖罪（通常要查到它做過的事） | 留下來當陰兵，**最後一戰加入隊伍** |
| **押送地府** | 隨時可以 | 交給陰間處置；活人得救，但冤情沒解，因果簿記一筆「未明」 |
| **斬** | 隨時可以 | 立刻了結。若它確實罪大惡極，沒有代價；**若斬錯了有冤的鬼，因果簿記遺憾、士氣下降** |

- 判決選項上寫明「目前已查明的部分」與會發生什麼，**沒查清楚的部分會標示「真相未明」**。玩家知道自己在冒什麼險，但不會直接告訴他答案。
- 判官會插話給提示（武判官急著要斬，文判官說「再問問」），讓玩家知道還有疑點。

## 5. 最後一戰：魔王戰（打＋審）

### 5.1 陣形

- 我方神轎在左，魔王從右邊來，帶著小妖。
- **不分前後左右**：近戰（八將、醒獅、收編的前鋒）衝上去打；遠程（鞭炮、令旗）在神轎前面射；七爺八爺專捉小妖。
- 法術維持兩顆大按鈕（天令、淨符），冷卻制。

### 5.2 打到一半要升堂

- 魔王的煞氣打到 70%、40%、10% 時，戰鬥暫停，進入**陣前審問**（一輪問答，出示一張證據）。
- 對了：魔王動搖，防禦下降、跳過下一次衝鋒，或收編的鬼上前說話。
- 錯了：魔王暴怒，攻擊變強。
- 最後一輪之後判決：**喚回**（石駒歸隊）、**送回山中**、**斬**。三種結局不同。

### 5.3 前面累積的東西怎麼影響最後一戰

| 累積來源 | 影響 |
|---|---|
| 收編的鬼 | 加入戰鬥，各有特色（見第 6 章的案子） |
| 信徒人數 | 鞭炮組火力（沿用現有公式）、神轎耐久 |
| 拿到的證據 | 陣前審問能出示的牌；牌越多，越容易喚回 |
| 白天幫過的人 | 部分人物會在最後一戰出現（例如小芸到場呼喊） |
| 斬錯、遺憾 | 士氣下降：陣頭出手變慢 |

香火的用途改為：白天辦事、超渡的紙錢與牌位。**取消原本逐項升級的廟宇經營**（待確認，見第 8 章）。

## 6. 案子（原型先做 3 件，加上小妖）

### 案一：古井邊的阿桂（第一天・菜市場）

**白天看到的**

- 阿秀嬸的孫子阿弟夜夜啼哭、發燒。
- 菜市場角落有一口用鐵板蓋住的古井，井邊蹲著一個穿大襟衫的女人，一直望著阿秀嬸的攤子。

**可以拿到的證據**

| 證據 | 怎麼拿 | 種類 |
|---|---|---|
| 阿秀嬸：「每晚子時哭，摸他額頭冰冰的，可是又在燒。」 | 處理阿秀嬸那件事時順便得到 | 證詞 |
| 鐵板下一個沒人認的小香爐，香早就斷了 | 線索（1 時辰） | 物證 |
| 布莊老闆娘：「早年井邊有個賣粿的阿桂。她的囝仔發燒，那晚沒有醫生肯來……後來她也走了。」 | 問話（1 時辰） | 證詞 |
| 青嶺宮廟誌：無主牌位「陳門阿桂」，自從管理人過世就沒人上香 | 黃曆頁或廟公阿土伯 | 文獻 |

**夜審供詞**

1. 「我沒有害那個囡仔。」
2. 「我只是去看看他睡得好不好。」
3. 「我在等我的囝仔回來。」
4. 「這世間已經沒人記得我了。」

**真相**

| 層 | 出示 | 揭開 |
|---|---|---|
| 一 | 阿秀嬸的證詞 → 對第 2 句 | 她每晚去摸阿弟的額頭，「像以前摸我的囝仔」。亡者的手是冷的，孩子因此生病。她不是故意的。 |
| 二 | 布莊老闆娘的證詞 → 對第 3 句 | 她的孩子很早以前就走了，她一直不肯接受。 |
| 三 | 廟誌牌位或小香爐 → 對第 4 句 | 她有牌位，只是沒人上香了。她以為自己被忘了。 |

**判決**

| 判決 | 結果 |
|---|---|
| 化解超渡（需真相二、三） | 重新為牌位上香，她放下等待離開。阿弟退燒；阿秀嬸在市場幫忙號召，信徒增加。 |
| 收編為「護嬰娘」（需真相一） | 她答應不再碰孩子，留下來守護。**最後一戰：淨符回復量提高、會照顧倒下的陣頭。** |
| 押送地府 | 阿弟退燒，但因果簿記「阿桂的冤情未明」。 |
| 斬 | 阿弟退燒。**斬錯了**：因果簿記遺憾，士氣下降，文判官不語。 |
| 今晚沒審 | 阿弟燒得更重（期限：第二天黃昏）。 |

### 案二：河岸的阿標（第一天・河岸／國小）

> 這一件是「鬼會說謊」的教學，也是可以理直氣壯斬的案子。

**白天看到的**

- 國小門口，小芸說：「河邊有一個濕濕的叔叔，一直叫我下去幫他撿球。」
- 河堤下的水裡站著一個男人，全身濕透，對著路過的孩子招手。

**可以拿到的證據**

| 證據 | 怎麼拿 | 種類 |
|---|---|---|
| 小芸的話 | 處理小芸那件事時得到 | 證詞 |
| 河堤欄杆上一條新綁的紅布條（上個月有人差點溺水，家屬綁的） | 線索（1 時辰） | 物證 |
| 老人會長輩：「阿標喔，喝醉酒跳下去游，誰勸都不聽。」 | 問話（1 時辰） | 證詞 |
| 舊聞：水鬼要「抓交替」才能離開 | 黃曆頁 | 文獻 |

**夜審供詞**

1. 「我是被人推下去的！我要找那個人討公道。」
2. 「我在那裡三十年，從來沒害過人。」
3. 「那個查某囡仔是自己要下來玩的。」
4. 「放我走，我就不會再回來。」

**真相**

| 層 | 出示 | 揭開 |
|---|---|---|
| 一 | 長輩證詞 → 第 1 句 | 沒有人推他，是他自己喝醉跳下去。 |
| 二 | 紅布條 → 第 2 句 | 上個月他拖過一個人，差一點就「抓到交替」。 |
| 三 | 小芸的證詞 → 第 3 句 | 是他引誘小芸。他想找人替他留在水裡，因為他怕一個人再待三十年。 |

**判決**

| 判決 | 結果 |
|---|---|
| 斬（查到真相二以上就**沒有代價**） | 河岸從此平安。武判官：「早該如此。」 |
| 押送地府 | 河岸平安。 |
| 收編為「前鋒」（需三層全查明，他才肯認罪） | 他願意贖罪。**最後一戰：衝最前面的近戰，血厚。** |
| 放走（相信第 4 句） | 他會再去抓交替：第二天「河岸又出事了」，小芸的故事變成遺憾。 |

### 案三：牽馬的阿福（第二天・芝林；主線，接魔王戰）

**白天看到的**

- 芝林菜園被啃光，地上有大蹄印。阿雄說要上山「抓那頭畜生」（同 v0.1）。
- 蹄印旁邊有一個老人的鬼，手裡拿著一截斷掉的韁繩，一直往山上看。
- 石材行的林伯一邊磨石，一邊說石駒的傳說（同 v0.1）。

**可以拿到的證據**

| 證據 | 怎麼拿 | 種類 |
|---|---|---|
| 林伯說的石駒傳說：聖王離開後，石駒被留在山裡；莊人鑿牠的肚子 | 問話（2 時辰） | 證詞 |
| 斷掉的韁繩，上面刻著「福」 | 收容阿福時一起帶回 | 物證 |
| 阿雄：「蹄印都是往北，一路往龍嶺寺那邊去。」 | 處理阿雄那件事 | 證詞 |
| 惠澤宮籤詩：「若得舊人呼一聲，不須鞭策自歸宮」 | 第三天黃曆頁 | 文獻 |

**夜審供詞**

1. 「石駒是惡獸，該斬。」
2. 「我只是剛好死在那座山上。」
3. 「我跟那匹馬沒有關係。」

**真相**

| 層 | 出示 | 揭開 |
|---|---|---|
| 一 | 韁繩 → 第 3 句 | 他是當年替聖王牽馬的馬伕。 |
| 二 | 林伯的傳說 → 第 2 句 | 聖王離開那天，他把石駒綁在山上，說「等我回來」，卻再也沒回去（他在路上病死了）。石駒一直在等。 |
| 三 | 阿雄的證詞 → 第 1 句 | 石駒往北走，是在找當年離開的路。牠不是作惡，是在找人。阿福說牠該斬，是因為愧疚，不敢面對。 |

**判決**

| 判決 | 結果 |
|---|---|
| 收編（需真相二以上） | 他願意去見石駒。**最後一戰的陣前審問，他可以上前喊石駒的名字（最強的一張牌）。** |
| 化解超渡 | 他安心離開，但最後一戰少了「舊人」。 |
| 押送地府／斬 | 最後一戰少了「舊人」；斬的話因果簿記遺憾。 |

## 7. 魔王：石駒（第三夜）

### 戰鬥

- 石駒從右邊衝來，身邊是白天沒驅散的小妖。
- 衝鋒、喘息的節奏沿用現有設計。

### 陣前審問（三輪）

| 輪 | 石駒的態度 | 可以出示 | 對了的效果 |
|---|---|---|---|
| 一（70%） | 「你們跟那些拿鑿子的人一樣。」 | 阿雄被勸阻的事（他沒上山設陷阱） | 防禦下降 |
| 二（40%） | 「他說會回來。他沒有回來。」 | 林伯的傳說、韁繩 | 跳過下一次衝鋒 |
| 三（10%） | 沉默，往北看 | **阿福（收編過）上前**／籤詩／小芸呼喊 | 可以喚回 |

### 結局

| 判決 | 條件 | 結局 |
|---|---|---|
| 喚回 | 三輪都對，或阿福在場 | 石駒歸隊，成為青嶺王的坐騎 |
| 送回山中 | 打贏但審不清 | 石駒回山裡繼續等；信徒錄記「石駒仍在等」 |
| 斬 | 隨時可以 | 石駒化成碎石；信徒錄記遺憾 |
