# 遶境（暫定名稱）

台灣環島進香 × 斬妖 × 廟宇經營。

你是一位神明。白天，你的進香隊伍沿著台灣一路祈福；晚上，隊伍駐駕的廟埕就是斬妖的戰場——而凡人什麼都看不見。

## 目前狀態：原型「青嶺王暗訪」

三天晝夜、一隻區域魔王：

| 天 | 白天（陽間） | 晚上（靈界） |
|---|---|---|
| 第一天 | 萬舺街區祈福，事件與擲筊 | 暗訪：夜巡捉拿小妖 |
| 第二天 | 萬舺 → 芝林 | 守夜：守住庄頭廟 |
| 第三天 | 芝林 → 芝嶺巖惠澤宮 | 魔王戰：與開疆聖王聯手喚回石駒 |

- 白天：隊伍原地前進、背景往後捲；事件選擇與擲筊影響香火、信徒、士氣。
- 黃昏：妖怪視角過場。
- 夜晚前：布陣（陣頭站神轎哪一邊）與升級。
- 夜晚：自動戰鬥，玩家可放「天令」「淨符」兩個法術。
- 天亮：判官審問捉到的小妖，供詞就是下一夜的情報。

## 開發

```bash
npm install
npm run dev      # 開發伺服器
npm test         # 戰鬥平衡測試
npm run deploy   # 建置並推到 gh-pages（GitHub Pages）
```

測試用網址參數：`?scene=night&n=3` 直接跳到第三夜、`?ts=4` 時間快 4 倍。

技術：Phaser 3 + TypeScript + Vite，美術全部以程式即時繪製，沒有圖檔。
