# 遶境（暫定名稱）

台灣環島進香 × 斬妖 × 廟宇經營。

你是一位神明。白天，你的進香隊伍沿著台灣一路祈福；晚上，隊伍駐駕的廟埕就是斬妖的戰場——而凡人什麼都看不見。

## 線上試玩

<https://sy19870627.github.io/taiwan-procession/>

## 目前狀態：原型「青嶺王暗訪」

三天晝夜、五位信徒、一隻區域魔王。核心一句話：**神明很忙，顧不了每個人。**

- **黃曆頁**：每天翻開一頁泛黃的舊黃曆，直書的宜忌、沖煞與廟誌舊聞；「昨日」欄寫出沒照顧到的人發生了什麼。
- **白天（街區地圖）**：兩條路線只能選一條；一天 5 個時辰（第三天 4 個），沿路停轎處理信徒卡。每個選項的花費、結果、不處理的後果與期限都寫在卡上。
- **神蹟**：每天限 1 次（第三天 2 次），香火 20，當晚妖怪 +2 波且從正面來。
- **因果簿**：隨時查看每位信徒的狀態、期限，以及今晚的戰況。
- **夜晚**：布陣、隊伍整備（逐項升級）、自動戰鬥。直式畫面：上方是橫向的戰鬥帶，下方是陣頭血量與兩顆大法術按鈕；各陣頭有自己的特色（勾魂鎖、格擋、震退、驚嚇），「天令」「淨符」兩個法術採冷卻制。
- **天亮審判**：捉到的小妖招出情報，解鎖信徒卡上的新選項。
- **結局「信徒錄」**：每位信徒的圓滿或遺憾；一次遊玩救不了所有人。

| 天 | 白天 | 晚上 |
|---|---|---|
| 第一天 | 萬舺：市場線／學校線 | 暗訪 |
| 第二天 | 萬舺 → 芝林：大路線／河堤線（最難的取捨） | 守夜 |
| 第三天 | 芝林 → 芝嶺巖：山腳線／街區線，最後到惠澤宮會香 | 喚回石駒 |

## 開發

```bash
npm install
npm run dev      # 開發伺服器
npm test         # 戰鬥平衡測試
npm run deploy   # 建置並推到 gh-pages（GitHub Pages）
```

測試用網址參數：`?scene=map&n=2` 直接跳到第二天地圖、`?scene=night&n=3` 第三夜、`?ts=4` 時間快 4 倍。

技術：Phaser 3 + TypeScript + Vite，美術全部以程式即時繪製，沒有圖檔。
