# 遶境（暫定名稱）

台灣環島進香 × 斬妖 × 廟宇經營。

你是一位神明。白天，你的進香隊伍沿著台灣一路祈福；晚上，隊伍駐駕的廟埕就是斬妖的戰場——而凡人什麼都看不見。

## 目前狀態：原型「青嶺王暗訪」（收容與夜審版）

- **出巡圖**：標題之後的臺灣大地圖選章節，目前開放萬舺・青嶺王暗訪，其他章節標示未開放。
- **過場**：起駕（鑼鼓鞭炮、隊伍出發）、日落升堂、雞啼天亮、石駒現身，點一下可跳過。
- **音效**：鑼、鼓、鞭炮、擲筊、蓋章、鎖鏈、雷、雞啼、馬嘶等，全部即時合成，沒有音檔；右上角可以切換聲音／靜音。

三天晝夜、五位信徒、四隻有冤情的鬼、一隻區域魔王。核心一句話：**神明管的是人，也是鬼。**

- **黃曆頁**：每天翻開一頁泛黃的舊黃曆；「昨日」欄寫出沒照顧到的人發生了什麼。黃曆上的文獻會收進證物袋。
- **白天（隊伍出巡）**：隊伍沿街前進，路上會遇到人、鬼、小妖、線索、問話；停下來處理才花時辰，略過就走過去了。每天一次岔路。
  - 鬼收容回令旗下（3 格），晚上審。
  - 線索、問話、信徒說的話都會收進**證物袋**。
- **晚上（夜審）**：升堂審問收容的鬼。追問供詞、在對的那一句出示證據，揭開真相；判決可以化解超渡、收編、押送地府或斬。也可以改日再審（怨氣 +1）。
- **戾氣**：斬是不得已的手段。斬一次戾氣 +1（斬錯有冤的鬼再 +1），白天鬼魂會躲起來或逃走；化解超渡可以降低戾氣。
- **最後一戰（打＋審）**：第三夜喚回石駒。陣頭分前排（最多 3 個）和後排，點卡片換位（走 2 秒）；前排挨打，後排近戰回血，輪流上陣扛傷害。石駒刨地預告衝鋒、衝完喘息可以打肚子。煞氣打到 70%、40%、10% 時陣前審問，出示證據或請收編的阿福上前。收編的鬼會加入戰鬥（前鋒阿標、護嬰娘阿桂、冰水伯阿添）。最後判決：喚回、送回山中或斬。
- **結局「信徒錄」**：每位信徒與每個鬼的圓滿或遺憾。

## 開發

```bash
npm install
npm run dev      # 開發伺服器
npm test         # 最後一戰的平衡模擬
npm run deploy   # 建置並推到 gh-pages（GitHub Pages）
```

測試用網址參數：`?scene=day&n=2` 直接跳到第二天白天、`?scene=boss` 最後一戰、`?ts=4` 戰鬥快 4 倍。

技術：Phaser 3 + TypeScript + Vite，美術全部以程式即時繪製，沒有圖檔。
